# Contributing

This project is currently in early prototype stage. Contributions should focus on podcast workflow clarity, media safety, and useful creator outputs.

## Before changing content or code

- Read `README.md`.
- Read `SECURITY.md`.
- Check `docs/ROADMAP.md`.
- Do not add real secrets, private voice data, client scripts, raw recordings, or generated exports.

## Branch style

Use short, descriptive branch names:

- `feat/episode-workflow`
- `feat/show-notes-template`
- `docs/avatar-handoff`
- `chore/security-cleanup`

## Commit style

Use simple conventional-style commits:

- `feat: add episode outline template`
- `docs: add podcast workflow notes`
- `fix: clarify prompt instructions`
- `chore: tighten media safety rules`

## Pull request checklist

- No secrets committed.
- No private voice/audio/client content committed.
- Prompt or workflow changes are documented.
- README or docs updated if behavior changed.
- Security impact considered.
