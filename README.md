# PodForge AI

PodForge AI is a prompt foundation for a podcast-focused AI assistant that helps creators plan, write, refine, and package podcast episodes.

## Master Prompt

The repository's primary artifact is [`MASTER_PROMPT.md`](MASTER_PROMPT.md), which defines PodForge AI's role, operating principles, workflow, output standards, and safety rules.

Use it as the system-level instruction for podcast production workflows such as:

- Episode ideation and positioning
- Research organization
- Outlines and beat sheets
- Full scripts
- Interview prep
- Show notes
- Promotional copy
- Clip and repurposing ideas
