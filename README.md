# PodForge AI

AI podcast video studio for multi-speaker conversations, avatar hosts, scripted episodes, and creator-focused production workflows.

## Purpose

PodForge AI is built to support podcast-style content generation with AI avatars, voice workflows, video scenes, backgrounds, scripts, and repeatable publishing packages.

## Core direction

- Multi-speaker AI podcast planning
- Script and episode generation
- Avatar/video production workflow
- Background and scene packaging
- Short-form clips and promo assets
- Creator dashboard support
